# logistics-management-system
logistics management system

This project was inspired by my experience in e-commerce. During that time, I managed more than 1400 orders and relied heavily on the logistics service provided by a delivery company.

Although their delivery service was great, I noticed several issues with the logistics management website I used every day. Some workflows were inefficient, and certain features could have been designed better to improve the overall user experience.

This project is my attempt to build a modern logistics management system that addresses those issues while following high-quality software engineering practices. My goal is to create a reliable, scalable, and user-friendly platform that simplifies logistics operations.
